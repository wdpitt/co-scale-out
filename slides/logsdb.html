LogsDB Index Mode

Store more.
Pay less.

LogsDB rewrites the storage contract for log data — keeping everything you need and dropping everything you don't.

Doc-values only storage — eliminates the inverted index for fields that don't need full-text search, cutting per-field overhead significantly
Synthetic _source reconstruction — source documents are rebuilt on-read from doc values, removing the largest single storage cost
TSDS-style column compression — time-series sorting groups similar values together, enabling much higher compression ratios
Fully transparent — same APIs, same query surface, same Kibana experience. No application changes required
